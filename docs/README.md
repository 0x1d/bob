# Documentation for Bob System

## Overview

This folder contains all documentation for the Bob (Autonomous Self-Learning AI Agent) system.

## Navigation

- **Specs:** [`specs/`](./specs/) - Core system specifications
- **Decisions:** [`decisions/`](./decisions/) - Specification decisions
- **Plans:** [`plans/`](./plans/) - Implementation plans
- **Research:** [`research/`](./research/) - Research documentation
- **Retrospectives:** [`retro/`](./retro/) - Post-mortem analyses

## Quick Start

1. Read [`specs/index.md`](./specs/index.md) to understand the system architecture
2. Review [`decisions/decisions.md`](./decisions/decisions.md) for past decisions
3. Find the domain you're interested in under [`specs/`](./specs/)

## Guidelines

- Write specs before implementing changes
- Document decisions before making architectural changes
- Create plans for significant implementation work
- Document research findings in this folder
- Write retrospectives after completing work
