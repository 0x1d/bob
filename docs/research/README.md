# Research

This folder contains research documentation that informs the Bob system specifications.

- [index.md](./index.md) - Research index

## Research Format

Each research entry is stored in a separate file with the format:

- **ID** - Unique research identifier (e.g., RES001)
- **Title** - Brief research title
- **Spec References** - Which specs this research informs
- **Sources** - Citations and references
- **Status** - ongoing | completed | archived
- **Findings** - Key findings from the research
- **Guidelines** - How to apply the research to specs

## File Naming Convention

Research entries are named `RESXXX.md` where XXX is the zero-padded number (e.g., RES001.md).

## Guidelines

1. Create a new research file when conducting research that will inform spec requirements
2. Number research entries sequentially (RES001, RES002, etc.)
3. Keep each research entry focused on a specific topic or spec area
4. Update the [index.md](./index.md) with the new link
5. Cite sources using consistent citation format
6. Link research to specific spec sections
7. Update status when research is completed or archived
