# Research Index

Canonical index for research documentation.

## Purpose

Research captures source-backed findings that inform specs and decisions.

## Research Format

Each entry should include:

- **ID** - unique identifier (e.g., `RES001`)
- **Title** - concise research objective
- **Spec References** - specs informed by the findings
- **Sources** - citations and links
- **Status** - `ongoing` | `completed` | `archived`
- **Findings** - distilled outcomes
- **Guidelines** - how to apply findings to specs/decisions

## File Naming

Use `RESXXX.md` with zero-padded numeric IDs.

## Authoring Rules

1. Create a research entry for new evidence-gathering work.
2. Keep each entry scoped to one topic or spec cluster.
3. Number sequentially and update this index in the same change.
4. Use consistent citation style and durable source links.
5. Link findings to specific specs or decision records.
6. Update status as work moves from ongoing to completed/archived.
