# Meta Documentation Index

Canonical index for meta documentation — guidance that applies across multiple lifecycle areas.

## Purpose

Meta docs provide cross-cutting conventions, workflows, and principles that govern how work is done throughout the system. Unlike area-specific docs (specs, research, etc.), meta docs are not tied to a single domain.

## Meta Docs

| Name | Link | Purpose |
|------|------|---------|
| Workflow: SDLC | [workflow-sdlc.md](./workflow-sdlc.md) | Software Development Lifecycle — overall process and integration across all lifecycle stages |

## Authoring Rules

1. Create meta docs for cross-cutting concerns that span multiple areas.
2. Keep each meta doc scoped to one topic or workflow.
3. Number sequentially and update this index in the same change.
4. Use consistent citation style and link to area-specific docs where relevant.
5. Update status as work moves from `ongoing` → `completed`.
