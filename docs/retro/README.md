# Retrospectives

This folder contains retrospectives from the Bob system specification and implementation process.

- [index.md](./index.md) - Retrospective index

## Retrospective Format

Each retrospective is stored in a separate file with the format:

- **ID** - Unique retrospective identifier (e.g., RETRO001)
- **Title** - Brief retrospective title
- **Spec References** - Which specs were reviewed or affected
- **Achievements** - What went well
- **Impediments** - Challenges encountered
- **Learnings** - Key takeaways and improvements
- **Date** - When the retrospective was written
- **Guidelines** - How to apply the learnings

## File Naming Convention

Retrospectives are named `RETROXXX.md` where XXX is the zero-padded number (e.g., RETRO001.md).

## Guidelines

1. Create a new retrospective file after completing work on multiple specs or implementation tasks
2. Number retrospectives sequentially (RETRO001, RETRO002, etc.)
3. Keep retrospectives focused on process improvements
4. Update the [index.md](./index.md) with the new link
5. Link retrospectives to specific spec changes
6. Use consistent retrospective IDs
